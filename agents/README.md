# agents

홈의 `~/.agents/`로 링크되는 원본 모음이다. 에이전트는 `~/.agents/...` 경로로 읽는다.

| 항목 | 내용 | 언제 읽나 |
|---|---|---|
| `pm-playbook.md` | 조직 성장 단계·주말 정례 검토·이름 규칙 | 담당 채용·분할·프로젝트 분리를 판단할 때 |
| `coding-principles.md` | 코딩 원칙 4가지 | 코드를 쓰거나 고치기 전 |
| `glossary.md` | 공통 단어사전 | 시작 때, 낯선 말이 나왔을 때 |
| `roles/` | 비서관·PM·담당 고유 지침 틀 | 에이전트를 만들 때(비서관은 항상) |
| `hooks/` | 세션 정리 알림 훅 | 훅이 자동 실행 |
| `skills/` | 전역 스킬(새 프로젝트, 새 환경 설정) | 해당 일을 할 때 |
| `templates/` | 상태 문서·계정 목록·줄임말·작업 환경·프로젝트 폴더 틀 | 새 환경·새 프로젝트를 만들 때 |
