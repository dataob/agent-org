# 조직도 작성·갱신

## 산출물
- **조직도** `~/.agents/org-chart.md`(홈 개인 기록): 순서대로 **요약 · 읽는 법 · 조직 구성 · 개정이력**만 적는다. 규칙 상세·어긋남은 넣지 않는다(오너 11-22). 작성 규칙은 이 스킬에만 적고, 산출물에는 규칙 문장·코멘트를 남기지 않는다
  - 머리말: `확인일` · `관리 담당` 한 줄
  - 요약 표(열: 프로젝트 · 폴더 · PM 세션 · 사이드바 섹션 · 명단 · 담당 수)
  - 읽는 법(몇 줄): 구조, 업무 표 열, 스킬 단계 표기, `없음`·`확인 안 함`·`-` 뜻. 아래 "표기"를 줄여 옮기고 규칙 상세는 쓰지 않는다
  - 프로젝트(H2): 개요 · 프로젝트 지침 · 프로젝트 스킬 > 담당(H3): `역할: 구분(지침: 경로)` + 업무 표
  - 전역 스킬은 따로 목록을 두지 않고 비서실 H2의 "프로젝트 스킬" 줄에 이름만 적는다
  - 맨 끝 "개정이력" 절: 표(일자 · 내용). 일자마다 한 줄. 같은 날 또 고친 것은 이력에 추가하지 않고, 새 일자에 처음 고칠 때만 맨 아래에 줄 추가
- 관리 주체: `01_조직관리`. 비서관은 직접 쓰지 않고 갱신을 요청한다
- 갱신 시점: PM의 재구성 알림(플레이북 8-1 7단계), 채용·정리 소식, 주말 정례 검토
- 완료 기준: 확인일 갱신, 바뀐 프로젝트·담당 반영, 개정이력(새 일자일 때만 한 줄), 확인 못 한 것은 "확인 안 함"
- 어긋남·신설 대상은 `org-chart-audit`의 산출물(`~/.agents/org-chart-gaps.md`)이다. 조직도에 옮겨 적지 않는다

## 표기
- 구분: 상설 / 임시 / 휴면
- 스킬 이름은 지침 경로처럼 SKILL.md 링크로 적는다: [`이름`](/절대경로/SKILL.md)(프로젝트 스킬은 그 프로젝트 `.agents/skills/`, 전역은 `~/agent-org/agents/skills/`). `신설`·`없음`·`확인 안 함`은 링크 없음
- 업무 표 열: 업무 · 세부 업무 · 스킬 · 산출물(고유 추가는 조직도에 넣지 않고 담당 지침의 스킬 표에 둔다). 스킬이 다른 세부 업무는 행을 나눈다. 빈 칸은 `-`
- 스킬 칸: 단계를 늘 붙인다 — `이름(전역)` / `이름(프로젝트)` / `이름(담당)`. `없음` = 전용 스킬 없이 지침 절차·지시서로 수행. `확인 안 함` = 지침에 스킬 배치가 적혀 있지 않음
- 산출물 칸의 `-` = 그 스킬에 산출물 정의가 아직 없음(해당 PM 반영 대기)
- 지침이 업무와 스킬을 짝지어 적지 않은 곳은 `(추정)`을 붙인다
- 담당 하나 = 지침 하나, 업무 하나 = 스킬 하나, 산출물 정의는 스킬 안에 있다. 지침 계층(전역 → 프로젝트 → 담당)·스킬 3단계(담당 → 프로젝트(PM 관리) → 전역(비서실 관리))·충돌 규칙의 정본은 전역 지침 1절이다. 조직도와 이 스킬에는 다시 적지 않는다

## 원천(읽기만)
1. 각 프로젝트 `AGENTS.md` 명단, `.agents/roles/` 파일 목록, 각 지침의 "쓰는 스킬" 표
2. 세션 목록(세션 목록 도구, 보관 포함)과 사이드바 그룹
3. 스킬 폴더(프로젝트 `.agents/skills/`, 전역 `~/agent-org/agents/skills/`)
4. 비서관 상태 문서 `~/.agents/status.md`(처음 만들 때만)

## 절차
1. 바뀐 프로젝트의 명단과 지침 표를 읽는다(전체 본문은 읽지 않는다)
2. 담당마다: 세션 이름, 구분, 지침 경로, 업무(스킬, 산출물), 세부 업무를 지침 표 그대로 옮긴다. 세분화는 지침을 쓰는 PM(전역은 비서관)이 하고, 조직도는 적힌 대로만 옮긴다
3. 지침에 없는 것을 추정해 채우지 않는다. 없으면 "없음", 확인 못 했으면 "확인 안 함"
4. 확인일을 고치고 맨 끝 개정이력에 새 일자일 때만 한 줄 추가한다(오늘 일자 줄이 이미 있으면 추가하지 않음)
5. 바뀐 줄만 비서관에게 보고한다

## 하지 않는 것
프로젝트 파일·지침·명단 수정, 세션 이름 변경·보관, PM·다른 담당에 직접 지시, 커밋·푸시. 어긋난 것은 보고만 한다.
