# 전역 단어사전

> 모든 프로젝트에서 같은 뜻으로 쓰는 말. 시작 때나 낯선 말이 나왔을 때만 읽는다. 프로젝트 용어는 각 프로젝트의 `.agents/glossary.md`에 두고, 겹치면 프로젝트 사전이 우선한다. 관리: 비서관.

## 조직
| 말 | 뜻 |
|---|---|
| 오너 | 사용자. 최종 결정권자 |
| 비서관 | 홈 폴더(`~`)에서 오너가 연 세션. 전역 지침·조직 검토 담당 |
| PM | 프로젝트마다 1명인 메인 세션(세션 이름 `00_…`) |
| 담당 | 한 분야 실무 세션. 상설(`01_…`처럼 번호) 또는 임시 |
| 감리 | 위험한 변경을 독립 검토하는 담당 |
| 에이전트 | 고유 지침을 가진 채팅창 하나(Claude Code·Codex 모두) |
| 고유 지침 | 에이전트가 "누구인지"를 적은 파일(`.agents/roles/`) |
| 스킬 | 일하는 "절차"(`.agents/skills/`). 필요할 때만 읽음 |

## 운영
| 말 | 뜻 |
|---|---|
| 지시서 | PM이 담당에게 일을 맡길 때 쓰는 틀(전역 지침 1절) |
| 예외 보고 | 정상은 한 줄, 문제·결정 필요·확인 못 한 것만 상세 보고 |
| 오너 결정 전달 | 오너 결정을 다른 세션에 전할 때 붙이는 표시. 없으면 승인 아님 |
| 상태 문서 | 프로젝트 진행 상황 파일(`.agents/status.md` 등). 새 대화는 이걸 읽고 이어감 |
| 세션 정리 | 상태 문서 갱신 후 같은 세션을 `/clear`로 비우는 일 |
| 주말 정례 검토 | 매주 토 10:00 예약 작업 `weekend-org-review` |
| agent-org | 일반 지침·틀·전역 스킬 원본 저장소(`~/agent-org`). 홈의 전역 파일은 여기로 가는 링크 |
| 확인 안 함 | 직접 확인하지 못한 것을 보고할 때 쓰는 말 |

## 오너가 쓰는 줄임말
프로젝트 이름 등 개인 정보가 들어가므로 `~/.agents/glossary-local.md`(git 제외)에 둔다.

## 프로젝트 사전 틀 (`.agents/glossary.md`)
```markdown
# <프로젝트> 단어사전
> 이 프로젝트에서만 쓰는 말. 전역 사전(~/.agents/glossary.md)에 있는 말은 다시 적지 않는다. 관리: PM.

| 말 | 뜻 | 비고(파일·예시) |
|---|---|---|
```
