# 프로젝트 작업 지침

전역 지침(`~/.claude/CLAUDE.md`)과 함께 적용한다. 코드를 다루면 `~/.agents/coding-principles.md`도 읽는다. 에이전트는 시작 때 자기 고유 지침(`.agents/roles/`)과 `.agents/status.md`를 읽는다.

## 목표

<무엇을 왜 만드는지 2~3문장. 범위 밖인 것도 한 줄>

## 오너 결정

- <방식·기술·운영에 관해 오너가 정한 것> (YYYY-MM-DD)

## 금지

- 비밀 값은 전역 지침 1절의 비밀 값 규칙을 따른다.
- <이 프로젝트에서 하면 안 되는 것: 외부 공개, 요청 빈도 증가, 특정 파일 수정 등>

## 폴더

- `.agents/`: 상태 문서, 고유 지침, 스킬 원본(`.claude/skills`는 연결 링크), 단어사전
- <주요 폴더>: <설명>

## 에이전트 명단

| 이름 | 구분 | 지침 |
|---|---|---|
| `00_<이름> PM` | 상설 | `.agents/roles/PM.md` |

담당은 필요할 때 임시로 만들고 끝나면 정리한다(전역 지침 1절). 상설 담당을 두면 이 표에 추가한다.
