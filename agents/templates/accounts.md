# 계정·키 목록 (값 없음)

> 어떤 비밀 값이 어디 있는지만 적는다. **값은 절대 적지 않는다.** 관리: 비서관(목록), 오너(값). (로컬 전용, git 제외)
> 값 위치: 전역 `~/.config/secrets/env`(오너만 편집, 권한 600) · 프로젝트 `.env*`(각 프로젝트, git 제외).
> 에이전트는 값 파일을 열지 않는다. 키 이름 확인이 필요하면 `cut -d= -f1`처럼 이름만 본다.

## 전역 (`~/.config/secrets/env`)
| 키 | 서비스·용도 | 쓰는 곳 | 비고 |
|---|---|---|---|
| (예) ANTHROPIC_API_KEY | AI API | 여러 프로젝트 | |

공용 키 추가: 오너가 전역 파일에 직접 적는다. 적은 뒤 이 표에 키 이름만 추가한다.
